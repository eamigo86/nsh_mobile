# NSH 0.6.0 upgrade

## Objective

Move the app from NSH 0.5.1 to 0.6.0 (released 2026-11-18) and keep every feature working.

## Scope and constraints

- Branch `chore/nsh-0.6.0` from `feat/nsh-home-swipe` (cbe2fd1).
- CLI and runtimes via `nsh update`; crates `nsh-core` and `nsh-platform-ios` to 0.6.0; `NSH_TAG` to v0.6.0.
- The uncommitted `package-ios` line in the Makefile stays out of this commit.
- TDD: strict (project setting). Runner: `make check`, `make test`.

## Breaking changes that touch this app

- None of the API breaks apply. The app does not use `maxLength`, `Clipboard.readText`, downloads,
  `AlertDialogOptions`, Rust `ContextMenu` listeners, `Transition`, `ModalConfig` or DataTable.
- The capability gate (`application`, `homeDir`) applies only to apps that use those APIs; this one does not.
- Found on device: packages now drop unused features (#1709). The packager kept `websocket` out because
  no module imports `websocket`; the global `WebSocket` does not count. On iOS the Market then stayed on
  "Connecting" and "Loading prices..." with no error (both the socket and the history fetch never settled).
  Fix: `import "websocket";` in `feed.ts`, after which the build reports "keep `websocket`".
