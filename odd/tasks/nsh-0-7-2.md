# NSH 0.7.2 upgrade

Locator: `odd/tasks/nsh-0-7-2.md` · Engram mirror: `odd/nsh-0-7-2/tasks` (project `exact_mobile`, where the NSH notes live)

## Objective

Move the app from NSH 0.7.1 to 0.7.2 (released 2026-11-27) and keep every feature working.

## Why

The user asked to update. 0.7.2 is a 2-commit patch on the 0.7.1 release line: Windows fixes (an abort when opening a
URL or showing a notification, updates, notifications, window icons, resizing, multiline `Input`), a macOS timer that
could spin the main thread, and two 0.7 regressions (`titleBar()` / `windowState()` outside a render, plain-text
children of a Rust component). Nothing targets iOS or Android.

It does NOT include the two fixes this app waits for: #3330 (a sheet stands on the keyboard the same way on every
platform; fixes longbridge/nsh#3288) and #3167 (`nsh update` keeps `~/.nsh` in place on macOS). So `KEYBOARD_ROOM` in
`ui/sheet.tsx` stays, and `nsh update` is expected to install into `~/nsh` again.

## Scope and constraints

- Branch `chore/nsh-0.7.2` from `main` (901d214).
- CLI and runtimes via `nsh update` (then the `~/nsh` workaround if needed); crate `nsh-core` to 0.7.2; `NSH_TAG` to
  v0.7.2; `make embed-libs`; README version.
- TDD: strict (project setting). Runner: `make check`, `make test`. No app code changes in the upgrade itself.
- Device checks with taps only on the emulator; back up the iOS app's data first.
- The planned switch to nsh-icon is a separate task, after the user picks the icon set.
