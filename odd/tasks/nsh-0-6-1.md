# NSH 0.6.1 upgrade

## Objective

Move the app from NSH 0.6.0 to 0.6.1 (released 2026-11-20) and keep every feature working.

## Scope and constraints

- Branch `chore/nsh-0.6.1` from `main` (466a7f0). `main` was created at 466a7f0 on 2026-11-20: every earlier branch
  is part of that single line of history.
- CLI and runtimes via `nsh update`; crate `nsh-core` to 0.6.1; `NSH_TAG` to v0.6.1; `make embed-libs`.
- TDD: strict (project setting). Runner: `make check`, `make test`. The app's own code does not change, so no new test.

## What 0.6.1 changes for this app

- longbridge/nsh#2368: app packages now build the app's Rust code for the oldest Apple system they declare (iOS 15.0).
  The Makefile workaround (`IPHONEOS_DEPLOYMENT_TARGET ?= 15.0` for `package-ios` and `ios-crate-device`) is no longer
  needed, so it is removed.
- longbridge/nsh#2448 (global `WebSocket` pruned from packages) is still open, and 0.6.1 does not change that. The
  `import "websocket";` in `feed.ts` stays.
- longbridge/nsh#2615: `svg` is optional again. The packager still keeps it for this app ("an image's format depends on
  data").
- No API breaks.

## Verification

- `make check`: OK. `make test`: 113/113, the same count as on 0.6.0.
- The simulator binary links `nsh-core` 0.6.1 and `nsh-platform-ios` 0.6.1.
- iOS simulator (`make ios-crate`): Home, Market (history, then Live), Tasks and the New Task sheet show.
- iOS device build with `IPHONEOS_DEPLOYMENT_TARGET` unset: it builds and links, and the binary has `minos 15.0`. Not
  installed on a device.
- Android (`make package-android`, API 35 emulator): Home, Market (Live), Tasks and the New Task sheet show.
- Not checked: the `native/` embed hosts (libs refreshed, hosts not rebuilt), a physical device, the Up next swipe and
  the date pickers.

## Finding

- iOS: when the New Task sheet opens with the on-screen keyboard (the title field has `autoFocus`), the sheet grows to
  full height and shows only its header; the form stays blank until the keyboard hides. Reproduced twice. Focusing the
  title after the sheet is open shows the form normally.
- Not a 0.6.1 regression: `main` (466a7f0) built with the official 0.6.0 CLI and iOS runtime (`nsh 0.6.0 (5541637)`,
  installed in a scratch folder) shows the same blank form on the same simulator, reproduced twice. With the on-screen
  keyboard off, the sheet opens with the form visible on both versions.

## Next step

None for the upgrade. The blank New Task sheet is an existing NSH behaviour, separate from 0.6.1; decide later whether
to report it to NSH or drop `autoFocus` from the title.
