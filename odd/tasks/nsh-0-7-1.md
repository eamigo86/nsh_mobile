# NSH 0.7.1 upgrade

Locator: `odd/tasks/nsh-0-7-1.md` · Engram mirror: `odd/nsh-0-7-1/tasks` (project `exact_mobile`, where the NSH notes live)

## Objective

Move the app from NSH 0.7.0 to 0.7.1 (released 2026-11-25) and keep every feature working.

## Why

The user asked to stay current. 0.7.1 is a 23-commit patch for Windows, macOS and Linux canvas work, GStreamer and
media linking, the nshm CLI and the web bundle. No commit touches iOS, Android, the keyboard or sheets, and
longbridge/nsh#3288 is still open, so no app code is expected to change.

## Scope and constraints

- Branch `chore/nsh-0.7.1` from `main` (2b79ba2).
- CLI and runtimes via `nsh update`; crate `nsh-core` to 0.7.1; `NSH_TAG` to v0.7.1; `make embed-libs`.
- README: the NSH version.
- TDD: strict (project setting). Runner: `make check`, `make test`. No app code changes, so no new test.
- Device checks with taps only on the emulator; back up the iOS app's data before touching the simulator.
- Delivery: `ask-on-risk`; tiny diff; push only with the user's OK.

## Verification

- CLI `nsh 0.7.1 (f78eace)`; runtimes ios, android, web and gpui. `cargo update -p nsh-core`: nsh-core and nsh-macros
  0.7.1. Embed libs v0.7.1, SHA-256 OK. Both packaged binaries contain `nsh-core-0.7.1`.
- `make check`: pass. `make test`: 113 passed, 0 failed (2 min 1 s on the first run after the upgrade).
- iOS 26.5 simulator (iPhone 17 Pro), `make ios-crate`: the existing data loads (4 tasks; checked in `todo.sqlite`
  before and after); Market goes Live; the New Task sheet opens whole above the on-screen keyboard; one tap on
  "Add date" sets today and hides the keyboard; X closes the sheet.
- Android API 35 emulator, `make package-android`: Market goes Live; the New Task sheet sits above the keyboard with the
  whole form (the keyboard showed after about 2 s); X closes it. Taps only.
- Not checked: dark mode, the photo picker, location, the swipe, a physical device, the `native/` embed hosts.

## Findings

- `nsh update` from 0.7.0 installed 0.7.1 into `~/nsh` (no leading dot) instead of `~/.nsh`, removed `~/.nsh`, then
  failed with "add the components again: No such file or directory". The `~/.local/bin/nsh` link was left dangling.
  Fixed by moving `~/nsh` back to `~/.nsh` and running `make components` (plus `nsh component add gpui`). Not reported
  upstream yet.
